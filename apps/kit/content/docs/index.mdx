---
title: UI Kit
description: Highlight text, pick a hue, share a quote card. Copy the source and own it.
---

Built on Radix primitives. If your project is on Base UI, initialize it with:

```bash
npx shadcn@latest init -b radix
```

Then install one item:

```bash
npx shadcn@latest add https://ui.souravinsights.com/r/highlight.json
```

The source lives in `packages/registry`. Install it, then edit it.
