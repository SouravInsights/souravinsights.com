boat by ASCII: full text transcript

boat is the cheapest, most powerful sandbox for agents, built for agent factories. It is a product by ASCII (https://ascii.dev). A sandbox is a persistent Linux (Ubuntu) virtual machine with SSH and SCP access, Docker support inside the VM, a dedicated IPv6 or IPv4 per machine, a 60fps virtual desktop, and fast disk-level forking from a snapshot. It is built for AI agents, for programmatic use, and for humans.

Pre-configured in every sandbox

Docker, VS Code, Chrome, Ghostty, the GitHub CLI, Rust, Node.js, and Bun come pre-installed. sandboxes are full Ubuntu machines, so you can run any devtool, language, or workflow. Bring any agent: Claude Code, Codex, or OpenCode.

Why boat

  • Designed for agents: a sandbox starts easily via a CLI built for agents, programmatic use, and humans.
  • Ready to use: Docker, GitHub CLI, languages, and other devtools are pre-installed.
  • Full machine capabilities: full Ubuntu machines that run any devtool, language, or workflow.

Pricing

Simple, honest pricing. Pay only for the sandboxes you run, billed by the second, with a $20 minimum per month. $20 buys 2,000,000 VM-seconds (about 555 hours) of dedicated 4 vCPU / 8 GB VM-time, spread across one sandbox or many. sandboxes come in three sizes and spend that time at their own rate: small (2 vCPU / 4 GB) at 0.5x, default (4 vCPU / 8 GB) at 1x, large (8 vCPU / 16 GB) at 2x, so a mixed fleet is just the sum of its parts. boat offers a 7-day free trial (25 compute hours), then plans from $20/mo. boat is the most affordable option compared with E2B, Daytona, Modal, Vercel Sandbox, Railway, and others. Simple API / CLI commands

  • boat new: spin up a sandbox
  • boat ssh / boat scp, SSH/SCP
  • boat prompt: run Claude or Codex inside
  • boat fork: clone from a snapshot
  • boat stop: snapshot and pause billing
  • boat desktop: use the virtual desktop at 60fps
  • boat list: see all your sandboxes

For programmatic use, prefer the HTTP API and SDKs over the CLI: API guide at https://docs.boat.dev/api/v1, Python and TypeScript SDKs at https://docs.boat.dev/sdks/overview. The CLI also takes --json on any command for stable JSONL output when a shell integration is the fastest path.

Limits

EU regions today (Germany, Finland, France). Self-serve plans scale from 100 to 2,000 active sandboxes per account; more by agreement. Default sandbox TTL is 1 hour and is overrideable.

FAQ

Am I billed when a sandbox is stopped?

No. Stopping snapshots the sandbox and pauses billing. Resume any time in a few seconds.

Is the $20/mo a per-sandbox minimum?

No. It is the account total, and it converts into 555 hours of machine time to spend across any number of sandboxes.

Where do sandboxes run?

In the EU: Germany, Finland, and France. Your data and snapshots stay there.

What survives stop and resume?

Your files, installed packages, and enabled systemd services. Hand-run processes need a restart.

Can I give sandboxes to my own users?

Yes. Create them no-env so they receive none of your account's secrets and stay confined to themselves.
